写代码

语法高亮
关键字、字符串、模板、注释、数字各一色；深色主题配了另一套配色，不是简单反色。
自动补全
边打字边提示。候选来自三处：JS 内置对象、这个文件里声明过的变量、以及下面那五个模板。
Ctrl+Space
代码模板
输入 for / forof / function / if / try，补全列表顶部会冒出绿色字样的完整结构（索引循环、for…of、函数、if…else、try…catch），回车即插入，光标落在该写代码的位置。
括号
输入 ( [ { 自动补上右半边；光标停在括号旁，配对的那个会加框。
同名变量高亮
双击一个变量，文件里其余同名处会用浅青底色标出来。注释和字符串里的同名词颜色更淡，一眼能分出「代码在用的」和「只是文字里提到」。
双击
折叠代码
鼠标移到行号区，行号右侧会出现折叠三角；点一下收起整块。展开用 Ctrl+Shift+]。
Ctrl+Shift+[
缩进
Tab 插入两个空格；选中多行再按 Tab 整体右移，Shift+Tab 左移。
Tab

运行

运行代码
在一个隐藏的沙箱 iframe 里执行，不刷新页面、不动编辑器里的内容。
Ctrl+Enter
看输出
console.log / info / warn / error 都按级别配色，对象和数组会展开成可读的一行。
报错定位
出错的栈会映射回编辑器里的真实行号，消息后面跟一个「第 N 行」，点它直接跳过去。
超时与停止
跑超过 3 秒会被自动终止；运行中也可以随时按「停止」。
一个拦不住的情况：while (true) {} 这种同步死循环会把浏览器主线程占死，任何超时都进不去。页面卡住时关掉标签页重开即可 —— 代码有自动保存，不会丢。

模拟网页 DOM

用途
编辑器里的 document 默认是张空白页。把目标网页的 HTML 贴进来，querySelector、innerHTML、style 就都有真实结构可操作了。
开启
点输出面板上的「模拟页面」，上方会展开一个输入框；按钮变蓝表示已启用。
Alt+M
规则
贴完整页面（含 <html> / <body>）也行，会自动取出 body 内容；页面里的 <script> 不会执行；每次运行前会清空重来，上一次改过的节点不会残留。
练手
点「示例」填一段商品列表，可以直接试 document.querySelectorAll('.item').length。
注意：贴进来的 HTML 如果带 <img src="https://…"> 或外链样式表，运行时真的会去联网加载。想保持离线干净，就只贴需要的那段结构。

检查与整理

语法检测
停止输入约 0.4 秒后自动解析。漏括号会指出缺的是哪一个（左括号还是右括号）、在第几行；常见英文报错都翻成了中文，状态栏会显示「语法检查通过」。
自动
格式化
重新缩进、补齐空格、对齐换行。已经排好的代码再按一次不会有变化。
Shift+Alt+F
压缩
删注释、去多余空白、安全合并行。留白的取舍按分号自动插入的规则来算，不会压缩出语义变化。
Shift+Alt+M
注释 / 取消注释
对选中的行切换行注释；没选中就作用于当前行。顶栏两个按钮也是同样的事，方便不知道快捷键的人。
Ctrl+/
查找与替换
双栏面板：上格找、下格替换。支持 /正则/flags 写法和 $1 到 $9 反向引用；命中处标黄，回车逐个跳，F3 / Shift+F3 前后翻。
Ctrl+F / Ctrl+H

文件与导出

打开
选一个本地 .js；或者直接把文件拖进窗口，松手就打开。
拖拽
保存
把编辑器里的内容存成 script.js 下载下来。
Ctrl+S
转 Bookmark JS
把当前脚本压成一行 javascript:…，粘进书签的网址栏，之后在任意网页上点一下这个书签，代码就在那个页面里跑 —— 这才是操作真实网页 DOM 的正路。弹窗里可以「复制链接」或「拖我到书签栏」，点「还原为代码」又能把链接变回可编辑的代码。
Shift+Alt+B
注释一条不少
书签链接只能是单行，所以 // 会改写成 /* */ 而不会被删掉；换行处的分号按语句边界补，生成后还会重新解析一遍对拍，语义对不上就自动退回更保守的写法。
自动保存
每次改动后约 0.5 秒写入浏览器本地存储，关掉页面再打开内容还在。顶栏右侧显示上次保存的时刻。
自动
书签脚本的限制：只能在普通网页上运行。chrome://、扩展管理页、新标签页这类浏览器内部页面禁止执行书签脚本，点了没反应是正常的。

状态栏
底栏常驻：点亮的就绪状态、光标在第几行第几列、全文多少字符、语法检查结果、当前字号。
窄屏
窗口窄于 760px 时自动改成上下排列，顶栏会收起次要文字，功能一个不少。
关于这个工具：整个编辑器就是一个 HTML 文件，没有任何外部依赖，断网也照常用。它跑在浏览器里，所以没有 require、fs、process 这些 Node 的东西，能用的就是浏览器 API 和 ES 新语法。草稿存在浏览器本地，换浏览器或者清缓存会丢 —— 重要的代码记得按「保存」。
